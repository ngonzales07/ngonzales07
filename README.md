## `01` / ABOUT ME

I'm a WordPress developer with **10 years of experience** building custom websites, scalable content management systems, and engaging digital experiences.

My work focuses on bridging the gap between design and development — transforming Figma designs into responsive, high-performance websites while building custom functionality that makes WordPress more powerful.

I enjoy working across the stack, from developing custom PHP themes and plugins to building React-powered Gutenberg blocks and interactive frontend experiences.

- Custom WordPress theme and plugin development
- Advanced Custom Fields (ACF) and flexible content architecture
- Custom Gutenberg block development with React
- Responsive frontend development and UI interactions
- Website performance, accessibility, and optimization
- Ongoing maintenance and development of production websites
